# CTĐT E2E

Dự án pnpm độc lập dùng Playwright, chỉ giao tiếp HTTP với ứng dụng đã chạy.
Không import, khởi động hoặc cài phụ thuộc backend/frontend.
Pilot: danh mục học phần; mọi test có TC_ID đối chiếu tài liệu tiếng Việt.
Hướng dẫn cài đặt, tài khoản, chạy và mở rộng: [playwright-guide.md](../../docs/testing/playwright-guide.md).
Các ca kiểm và truy vết: [test-cases](../../docs/testing/test-cases/README.md).
Chưa cài dependency, kiểm kiểu hoặc chạy trình duyệt trong lần dựng scaffold này.
